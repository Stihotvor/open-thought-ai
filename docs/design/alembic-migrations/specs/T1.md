# T1: Dependencies, db package, schema-name function, settings

## Context
The server has no database code. `ota_server.db` is the one place for names and settings (decision rules, Consequences). This task serves requirement constraints 1, 5, 7 and 8. T2 to T5 build on it.

## Technical Approach
- Run `uv add alembic sqlalchemy "psycopg[binary]"` in `server/`. This updates `server/pyproject.toml` and `server/uv.lock`.
- `server/src/ota_server/db/__init__.py`: package marker, small public exports only.
- `server/src/ota_server/db/names.py`: one function that takes `device_id`, checks `^[a-z0-9_]{1,40}$`, and returns the schema name `ota_<device_id>`. A second helper returns the quoted form with `psycopg.sql.Identifier`. Invalid input raises `ValueError`.
- `server/src/ota_server/db/settings.py`: settings class with env prefix `OTA_`. Fields: `device_id` and `database_url` (optional). Hide the URL from `repr` and `str` (use `SecretStr` or `repr=False`).
- Tests: `server/tests/test_db_names.py` and `server/tests/test_db_settings.py`.
- Models and migrations hold no schema name (constraint 5).
- Decision: use `pydantic-settings` (already used in `config.py`, prefix `OTA_`).

## Acceptance Criteria
```gherkin
Scenario Outline: Invalid DEVICE_ID is rejected
  Given the DEVICE_ID value "<value>"
  When the schema name function runs
  Then it raises ValueError
  Examples:
    | value                                      |
    |                                            |
    | aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa  |
    | Abc                                        |
    | a"b                                        |

Scenario: Valid DEVICE_ID gives a quoted schema name
  Given the DEVICE_ID "abc_1"
  When the quoted schema name is built
  Then the result renders as "ota_abc_1" with double quotes

Scenario: A 40 character DEVICE_ID is accepted
  Given a DEVICE_ID of 40 characters from [a-z0-9_]
  When the schema name function runs
  Then it returns "ota_" followed by the 40 characters

Scenario: The database URL is read from env and hidden
  Given the env variable OTA_DATABASE_URL is "postgresql://u:secret@h/db"
  When the settings load
  Then settings.database_url holds the URL value
  And repr(settings) and str(settings) do not contain "secret"
```
