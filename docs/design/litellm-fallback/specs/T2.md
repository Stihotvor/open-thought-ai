## Context
Issue #20 needs one example LiteLLM config for chat, STT, and TTS fallback. Serves B1, B2, B3, T4, T7, F3.

## Technical Approach
Write `docs/examples/litellm/config.yaml` as in `decision.md`. Define 7 model groups in `model_list`: `mistral-small-latest`, `chat-gemini`, `chat-local`, `voxtral-mini-latest`, `stt-local`, `tts`, `tts-local`. Set `router_settings`: `num_retries: 0`, `timeout: 2`, and fallbacks `mistral-small-latest -> [chat-gemini, chat-local]`, `voxtral-mini-latest -> [stt-local]`, `tts -> [tts-local]`. Every `api_key` and `api_base` is `os.environ/<NAME>`. Add no moderation group. Add short comments for the env names.
Accepted risk (F4): Exact LiteLLM provider prefixes and speaches model ids are unverified until issue #26 (F4). Use best-known values and mark them in comments.
