## Context
An owner must set up fallback in 15 minutes or less with the guide only (B1, M4). The guide also covers edge cases E1 to E3 and risks F3 and F4.

## Technical Approach
Write `docs/guides/litellm-fallback.md` with exactly 6 numbered steps `1. ` to `6. `, from "LiteLLM running" to "OTA uses it". Use no other numbered list. Content: copy `docs/examples/litellm/config.yaml`, set env names, set OTA role variables (`OTA_CHAT_MODEL` and `OTA_STT_MODEL` stay at default, `OTA_TTS_MODEL=tts`), one LiteLLM virtual key per role with its own base URL, restart. Notes: E1 remove Gemini, E2 LM Studio one-line change, E3 chat only, LAN rule (`OTA_ALLOW_INSECURE_MODEL_ENDPOINT=1` and a private IP), moderation stays direct to Mistral, the 8 s turn deadline, ADR 0002 (LiteLLM outside the stack), speaches setup link to `docs/guides/speech-server.md`. State "STT/TTS fallback untested, see #26" and that `/audio/*` fallback in LiteLLM is not confirmed.
Resolved: T2 is written. The guide uses `lm_studio/<model-id>` and `os.environ/LM_STUDIO_API_BASE` for the local deployment.
