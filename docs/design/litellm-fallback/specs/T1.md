## Context
The offline config test (T3) parses YAML and mypy runs strict. The project needs `pyyaml` and `types-PyYAML` as dev dependencies. Serves M5 and T6.

## Technical Approach
In `server/pyproject.toml`, add `pyyaml` and `types-PyYAML` to the dev dependency group. Run `uv lock` in `server/` to update `server/uv.lock`. Do not add them to runtime dependencies.

## Acceptance Criteria
Scenario: PyYAML imports
  Given the dev dependencies are installed
  When `cd server && uv run python -c 'import yaml'` runs
  Then the exit code is 0

Scenario: Lock file lists both packages
  Given `uv lock` ran
  When `server/uv.lock` is searched for the package names `pyyaml` and `types-pyyaml`
  Then both names are found

Scenario: Runtime dependencies stay unchanged
  Given the change is done
  When the `[project] dependencies` list is compared with main
  Then it has no new entry

## Definition of Done
- The task's `done_when` check passes.
- Tests exist for every scenario and pass.
- The quality gate reports pass or skipped (never fail).
- No `OPEN:` item remains.
