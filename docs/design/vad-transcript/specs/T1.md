# T1: Add vad.py trim_speech with unit tests

## Context
Silence and noise must end fast with `no_speech` and cost no STT call (B2, E1, E2, E3). This task builds the pure VAD function. T3 wires it into the pipeline.

## Technical Approach
Create `server/src/ota_server/vad.py` (stdlib only, no numpy, no `audioop`).
- Constants: `ENERGY_THRESHOLD = 500`, `MIN_SPEECH_MS = 300`, `MARGIN_MS = 200`. Frame size is 20 ms (640 bytes at 16 kHz s16le).
- `trim_speech(pcm: bytes) -> bytes | None`. Raise `ValueError` on an odd byte count.
- Read samples with `array('h')`. Compute the RMS of each frame with `math.sumprod`. A frame is speech when RMS is at least `ENERGY_THRESHOLD`. A last frame shorter than 20 ms is classified like a full frame.
- If the speech frames total less than `MIN_SPEECH_MS`, return None.
- Else return the span from the first to the last speech frame, plus `MARGIN_MS` on each side, clipped to the input.
- Create `server/tests/test_vad.py` with synthetic audio only (tone-like square or sine wave, silence, low noise with amplitude 300 or less).
- Byte order: use native `array('h')` on little-endian. Do not add a byteswap.

## Acceptance Criteria
```gherkin
Scenario: Speech between silences is trimmed
  Given 1 s silence, 1 s tone, 1 s silence as PCM 16 kHz s16le
  When trim_speech runs
  Then the result is not None
  And its length is at most 1.5 s (48000 bytes)

Scenario: Silence is rejected
  Given 3 s of zero samples
  When trim_speech runs
  Then the result is None

Scenario: Low noise is rejected
  Given 3 s of noise with amplitude at most 300
  When trim_speech runs
  Then the result is None

Scenario: Short speech is rejected
  Given 250 ms of tone inside silence
  When trim_speech runs
  Then the result is None

Scenario: Enough speech is kept
  Given 400 ms of tone inside silence
  When trim_speech runs
  Then the result is not None

Scenario: Speed
  Given 30 s of audio
  When trim_speech runs
  Then the best of 3 runs takes at most 50 ms

Scenario: Bad audio
  Given a PCM buffer with an odd byte count
  When trim_speech runs
  Then it raises ValueError
```
