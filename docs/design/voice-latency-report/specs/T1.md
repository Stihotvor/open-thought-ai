# T1 Timing module

Resolved: the turn id is an int from a counter in `VoicePipeline` (T2). The line carries `id=<int>`.

## Context
The server logs no stage time today. T2 and T6 need one shared module, so the writer and the reader of the log line cannot drift (B2, T2, T3, F1, F2).

## Technical Approach
Create `server/src/ota_server/timing.py` and `server/tests/test_timing.py`.
- `STAGES`: tuple `vad, stt, mod_transcript, chat_first_sentence, chat_full, mod_reply, tts1, selftest`.
- `StageTimer`: uses `time.perf_counter` only. Methods `start()`, `mark(stage)` (stores ms since the previous mark or start), `latency_ms`, `stages` (dict). Every method wraps its body in `try/except Exception`, logs with `log.exception`, and returns. It never raises (F1).
- `format_line(turn_id, code, latency_ms, stages) -> str` gives `turn.latency id=.. code=.. latency_ms=.. vad=..`. No text field (F5). Missing stages are left out of the line.
- `parse_line(line) -> TurnTiming | None`: inverse of `format_line`. Returns `None` for other lines.

## Acceptance Criteria
```gherkin
Scenario: line round trip
  Given a turn id, code "ok", latency 4200 and times for all stages
  When format_line output goes to parse_line
  Then the parsed values equal the input

Scenario: failed turn has no latency
  Given code "llm_failed" and latency None
  When format_line output goes to parse_line
  Then the parsed latency_ms is None and the code is "llm_failed"

Scenario: STAGES is complete
  Given the module STAGES
  When a test reads it
  Then it equals the eight stage names in order

Scenario: timer error does not raise
  Given a StageTimer whose clock raises an error
  When mark("stt") is called
  Then no exception reaches the caller and one error is logged

Scenario: other lines are ignored
  Given the line "hello world"
  When parse_line reads it
  Then the result is None
```
