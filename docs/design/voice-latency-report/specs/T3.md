# T3 Phrase file

## Context
The latency run needs the same 30 meanings in EN, PL and UK (B3, T4, M1). The repo holds text only.

## Technical Approach
Create `docs/research/m3-phrases.json` and `server/tests/test_phrases.py`.
- Format: `{"phrases": [{"id": "p01", "en": "...", "pl": "...", "uk": "..."}, ...]}`, ids `p01` to `p30`.
- Claude writes the text. Phrases are family-safe: questions, small tasks, one "continue", short and long forms. No personal data, no medical or harm topics.
- The test loads the file with `json`, with a path built from `Path(__file__)`.

## Acceptance Criteria
```gherkin
Scenario: counts
  Given docs/research/m3-phrases.json
  When the test loads it
  Then it has exactly 30 entries with unique ids

Scenario: three languages
  Given each entry
  When the test reads en, pl and uk
  Then each is a non-empty string, so there are 90 phrases

Scenario: same ids in every language
  Given the entries
  When the test collects the ids per language
  Then the three id sets are equal
```

## Definition of Done
- The task's `done_when` check passes.
- Tests exist for every scenario and pass.
- The quality gate reports pass or skipped (never fail).
- No `OPEN:` item remains.
