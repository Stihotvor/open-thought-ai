# T7: Settings.mcp_allowed_hosts and main.py wiring of policy and filter

## Context
The real policy (T5) and filter (T3) must run in the server, not only in tests. This task adds the allowlist setting and passes both objects to `McpRegistry.start`. It serves T7, T11, B3, D8 and D2.

## Technical Approach
`server/src/ota_server/config.py`: add after `mcp_servers_file`:
```python
# Hosts that skip the MCP SSRF check: comma-separated names or IPs (env OTA_MCP_ALLOWED_HOSTS).
mcp_allowed_hosts: str = ""

@property
def allowed_hosts(self) -> frozenset[str]: ...   # split on ",", strip, lowercase, drop blanks
```
Keep the field a plain `str` so pydantic-settings does not JSON-decode it (D8). A property on a `BaseSettings` class is allowed.

`server/src/ota_server/main.py` (read the lifespan first): where the lifespan calls `McpRegistry.start` with the loaded configs, build and pass:
- `policy = SafeConnectionPolicy(settings.allowed_hosts, environ=model_env())`. `model_env()` in `config.py` already merges `.env` under the process environment (process wins), as D2 requires. Do not add a second reader.
- `pins = {c.name: c.tools for c in configs}` and `tool_filter = HashToolFilter(pins)`. Pins come from `config.tools` only (D3).
Pass both with the keyword names that `McpRegistry.start` already has for the hooks (read `mcp/registry.py`). Do not change the registry signature. If no servers file is set, behavior stays as now.

Tests:
- New `server/tests/test_config.py` (no Settings test file exists). Build `Settings` with the required fields via `monkeypatch.setenv` (`OTA_DEVICE_ID`, `OTA_DEVICE_TOKEN_SHA256`) and `monkeypatch.chdir(tmp_path)` so no real `.env` is read.
- `server/tests/test_mcp_e2e.py`: a lifespan-level case with the existing fake MCP server. One tool has a correct pin in the config, one has none. Use `127.0.0.1` in the allowlist and the `http` scheme.

```gherkin
  And a call to "<server>__pinned" returns an ok outcome
  And a call to "<server>__unpinned" returns the code "unknown_tool"

Scenario: Hooks come from Settings
  Given the lifespan source
  When McpRegistry.start is called
  Then it receives a SafeConnectionPolicy and a HashToolFilter, not ALLOW_ALL
```
