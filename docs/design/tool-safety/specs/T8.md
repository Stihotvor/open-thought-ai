# T8: Update docs/security.md and servers file example

## Context
The servers file format changed: `tools` is a map of pins and `headers` hold `MCP_SECRET_*` names. The owner needs the rules and one working example (B3, #29 builds on it). It serves D10, T3, T7 and T9.

## Technical Approach
Edit `docs/security.md`, section "MCP hub and tools" (lines 33 to 42). Change the text only where #31 makes it true, and keep the other lines:
- Line 36: say the tool is pinned by a SHA-256 hash in the servers file `tools` map. A tool with a missing or different hash is not admitted, and the server logs the tool name and current hash at WARNING. A description over 1 000 chars or an input schema over 4 000 chars of canonical JSON is not admitted.
- Line 40: add that the allowlist is `OTA_MCP_ALLOWED_HOSTS` (comma-separated, default empty), `http` is allowed only to a loopback or allowlisted host, the check runs on connect and on each reconnect, and redirects fail the connect or call.
- Add an accepted-risk line for DNS rebinding (D, Consequences): the host is resolved twice, so a hostile DNS can return a safe IP first. Follow-up: an httpcore backend that connects to the vetted IP.
- Line 41: add that a `MCP_SECRET_*` name is in one entry only, a missing variable denies the server, and a stdio entry with a secret-like `env` key or a `MCP_SECRET_` value is rejected.
- Line 49 stays. The source name `device` is reserved.

Create `docs/examples/mcp/servers.json` (no example exists yet). It is a JSON list with two entries:
- An `n8n` entry: `transport` `http`, `url` `https://n8n.example.com/mcp`, `timeout` 10, `headers` `{"Authorization": "MCP_SECRET_N8N"}`, and `tools` as a map of one tool name to `"sha256:" + 64 hex` (use a clearly fake value such as 64 zeros).
- A stdio entry: `transport` `stdio`, `command`, `args`, a harmless `env` (for example `{"LOG_LEVEL": "info"}`) and `tools` as a map.
JSON has no comments. Explain the hash copy step in `docs/security.md` (copy the hash from the WARNING log into `tools`), not in the file. The file holds no real host, no real secret and no old list form.

Do not add a new test. The check is a one-line command that loads the file through `load_servers`.
